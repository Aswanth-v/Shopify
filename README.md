# Shopify Product Dashboard

A modern product dashboard built using **Next.js**, **TypeScript**, and **Shopify Polaris**. The application fetches products from the Fake Store API and displays them in a dashboard-style interface with search, filtering, and detailed product views.

## 🚀 Live Demo

https://shopify-aswa.vercel.app/

---

## ✨ Features

### Product Listing
- Fetches products from the Fake Store API
- Displays products using Shopify Polaris `IndexTable`
- Responsive dashboard layout

### Search & Filtering
- Search products by title
- Filter products by category
- Real-time filtering

### Product Details Modal
- View detailed product information
- Product image
- Product title
- Price
- Category
- Description
- Rating information

### Analytics Dashboard
- Internal dashboard built using AI-assisted development
- Demonstrates analytics and user behavior visualization concepts
